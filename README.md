## 1. Бағдарламаның мақсаты

«Тастардан жалтар!» — Python бағдарламалау тілінде Pygame кітапханасын пайдаланып жасалған екі өлшемді компьютерлік ойын.

Бағдарламаның негізгі мақсаты — ойыншының ғарыш кемесін басқара отырып, құлап келе жатқан тастардан жалтару, кедергілерді ату және мүмкіндігінше ұзақ уақыт тірі қалу.

Жоба объектіге бағытталған бағдарламалау принциптерін тәжірибе жүзінде қолдануға арналған. Бағдарламада мұрагерлік, инкапсуляция және полиморфизм принциптері жүзеге асырылған.

## 2. Бағдарламаның сипаттамасы

Ойын ғарыш кеңістігінде өтеді. Ойыншы ғарыш кемесін басқарады. Ойын барысында әртүрлі тастар, кометалар және НЛО пайда болады.

Ойын бес деңгейден тұрады. Әр деңгей өткен сайын ойынның күрделілігі артады. Ойыншы кедергілерден жалтарып, оларды атып жойып, қосымша бонустар жинай алады.

Бағдарламада келесі мүмкіндіктер қарастырылған:
- Ғарыш кемесін басқару;
- Тастарды ату және жою;
- Әртүрлі кедергілермен күресу;
- Қосымша бонустар жинау;
- Өмір санын бақылау;
- Ұпай жинау;
- Деңгейлерден өту;
- Жеңіс және жеңіліс жүйесі;
- Ойынды қайта бастау.

## 3. Бағдарламаны іске қосу нұсқаулығы

### 3.1 Қажетті бағдарламалық құралдар

Бағдарламаны іске қосу үшін келесі құралдар қажет:
- Python 3.x;
- Pygame кітапханасы;
- Visual Studio Code немесе басқа Python редакторы;
- Windows, Linux немесе macOS операциялық жүйесі.

Pygame кітапханасын орнату командасы:

`pip install pygame`

### 3.2 Бағдарламаны іске қосу

1. Жоба файлын компьютерге сақтау.
2. Python ортасын ашу.
3. Pygame кітапханасының орнатылғанын тексеру.
4. Бағдарлама орналасқан бумаға өту.
5. Негізгі файлды іске қосу.

Іске қосу командасы:

`python main.py`

## 4. Пайдаланушы нұсқаулығы

Ойыншы ғарыш кемесін пернетақта арқылы басқарады.

| Перне | Қызметі |
|---|---|
| W немесе ↑ | Жоғары қозғалу |
| S немесе ↓ | Төмен қозғалу |
| A немесе ← | Солға қозғалу |
| D немесе → | Оңға қозғалу |
| SPACE | Оқ ату |
| R | Ойынды қайта бастау |
| ESC | Ойыннан шығу |

Ойынның мақсаты — бес деңгейді сәтті аяқтап, барлық кедергілерден аман өту.

## 5. Кіріс деректер

Бағдарлама пайдаланушыдан тікелей мәтіндік немесе сандық деректерді енгізуді талап етпейді.

Ойынның негізгі кіріс деректері:
- Пернетақта командалары;
- Ойыншының қозғалыс әрекеттері;
- Ойын уақытын есептеу;
- Кездейсоқ пайда болатын тастар мен бонустар;
- Ойын деңгейлерінің параметрлері.

## 6. Деректер сипаттамасы

Бағдарламада келесі негізгі айнымалылар қолданылады:

| Айнымалы | Сипаттамасы |
|---|---|
| W, H | Ойын терезесінің өлшемдері |
| WORLD_W, WORLD_H | Ойын әлемінің өлшемдері |
| FPS | Бір секундтағы кадр саны |
| score | Ойыншының жинаған ұпайы |
| hp | Ойыншының өмір саны |
| speed | Қозғалыс жылдамдығы |
| level | Ағымдағы деңгей |
| time_scale | Ойын уақытының жылдамдығы |
| bullets | Ойыншы оқтарының тізімі |
| rocks | Тастар тізімі |
| ufos | НЛО нысандарының тізімі |
| pickups | Бонустар тізімі |

## 7. Функциялар мен кластардың сипаттамасы

Бағдарлама бірнеше негізгі кластан тұрады.

**GameObject** — барлық ойын нысандарының негізгі ата-аналық класы. Оның құрамында координаталар, радиус, өмір саны және соқтығысуды тексеру әдістері бар.

**Ship** — ойыншы басқаратын ғарыш кемесі. Қозғалыс, ату, өмір және бонустарды басқару міндеттерін орындайды.

**Bullet** — ойыншының атқан оғы. Оқтың қозғалысын және экраннан шығуын басқарады.

**EnemyShot** — НЛО ататын жау оғы.

**Rock** — ойын барысында пайда болатын тастарды сипаттайды. Қарапайым, сауытты және комета түрлері бар.

**UFO** — ойыншыға шабуыл жасайтын ұшатын нысан.

**Pickup** — ойыншы жинай алатын қосымша бонустарды сипаттайды.

**Game** — ойынның негізгі класы. Ойын циклін, деңгейлерді, соқтығысуларды, ұпайларды, жеңіс пен жеңілісті басқарады.

## 8. Объектіге бағытталған бағдарламалау принциптері

Жобада объектіге бағытталған бағдарламалаудың негізгі принциптері қолданылған.

**Мұрагерлік (Inheritance):** Ship, Rock, Bullet, UFO және Pickup кластары GameObject класынан мұра алады.

**Инкапсуляция (Encapsulation):** Әр класс өзіне тиесілі деректер мен әдістерді біріктіреді. Мысалы, Ship класы кеменің қозғалысы мен өмірін басқарады.

**Полиморфизм (Polymorphism):** Әртүрлі кластарда update(), draw() және hit() әдістері өз ерекшеліктеріне сәйкес орындалады.

**Әдістерді қайта анықтау (Method Overriding):** Мұрагер кластар ата-аналық кластың әдістерін өз қажеттіліктеріне сәйкес қайта анықтайды.

## 9. Бағдарламаның жұмыс логикасы

Бағдарлама іске қосылған кезде ойын терезесі ашылады және бастапқы деңгей басталады.

Ойынның негізгі жұмыс кезеңдері:

1. Ойын терезесін құру.
2. Ойыншының кемесін орналастыру.
3. Пернетақта командаларын қабылдау.
4. Тастар мен басқа нысандарды генерациялау.
5. Нысандардың қозғалысын жаңарту.
6. Соқтығысуларды тексеру.
7. Ұпай мен өмір санын жаңарту.
8. Деңгейдің аяқталуын тексеру.
9. Жеңіс немесе жеңіліс жағдайын анықтау.

Барлық бес деңгей аяқталған жағдайда ойыншы жеңіске жетеді. Егер ойыншының өмірі таусылса, ойын аяқталады.

## 10. Қорытынды

«Тастардан жалтар!» жобасын жасау барысында Python бағдарламалау тілі мен Pygame кітапханасының мүмкіндіктері пайдаланылды.

Жоба арқылы объектіге бағытталған бағдарламалау принциптері тәжірибе жүзінде қолданылды. Кластар құру, мұрагерлік, полиморфизм, әдістерді қайта анықтау және ойын логикасын ұйымдастыру дағдылары қалыптастырылды.

Бағдарлама пайдаланушыға ыңғайлы басқару жүйесін, бірнеше ойын деңгейін және әртүрлі ойын механикаларын ұсынады.
